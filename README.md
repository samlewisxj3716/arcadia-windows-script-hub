## About Arcadia

Arcadia is a Windows desktop tool for Lua injection and Roblox script execution. Its compact design provides a direct workflow for running scripts, accessing utilities, and browsing a built-in collection of more than 500 ready-to-use scripts.

The executor is built to remain lightweight while offering the controls needed for everyday script management on Windows 10 and 11. Auto-update support, a key-free setup, and multilingual interface options provide a simple desktop experience for working with Roblox scripts.
